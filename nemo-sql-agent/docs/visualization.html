03 Compounding returns are real — but they saturate

Returns are diminishing, not additive. Once a strong base model plus execution-grounded correction and good candidate selection are in place, marginal gains shrink — and CHASE-SQL shows a ~10-point oracle gap: the right query is often generated but not selected.
